Data Management
All logbook data is stored in this browser's localStorage. Export a JSON backup regularly — data will be lost if browser storage is cleared.
Danger ZoneClearing data is irreversible. Export a backup before proceeding.

• Data lives in this browser on this device only.

• To share: export JSON, share file, teammates import it.

• For shared team access: move to a backend REST API (SQLite / PostgreSQL). The frontend is structured to support this.
